## 设计规范

### 颜色方案

#### 主色调
- 主色: `#1890ff` (蓝色)
- 辅助色: `#52c41a` (绿色)
- 警告色: `#faad14` (橙色)
- 错误色: `#f5222d` (红色)

#### 中性色
- 背景: `#f0f2f5`
- 卡片背景: `#ffffff`
- 文本主色: `#262626`
- 文本次色: `#595959`
- 边框色: `#d9d9d9`

### 字体层级
- 标题: `1.5rem / 700`
- 副标题: `1.25rem / 600`
- 正文: `1rem / 400`
- 小字: `0.875rem / 400`

### 间距规范
- 超小: `4px`
- 小: `8px`
- 中: `16px`
- 大: `24px`
- 超大: `32px`

## 页面设计

### 1. 首页 (HomeView)

#### 布局
- 居中卡片式布局
- 顶部：项目标题和logo
- 中部：游戏模式选择
- 底部：设置选项

#### 设置选项
- AI 难度（简单/普通/困难）
- 团队交流开关（默认开启）
- 房间 ID 输入框

#### 交互流程
```
用户进入首页 → 选择模式 → 配置选项 → 创建/加入房间 → 进入游戏
```

### 2. 游戏页面 (GameView)

#### 整体布局
```
┌─────────────────────────────────────────────────────────────┐
│                                                               │
│                    [上方玩家区域]                             │
│                                                               │
│  [左侧玩家]              [出牌区]              [右侧玩家]    │
│                                                               │
│                    [出牌历史]                                 │
│                                                               │
│  ┌─────────────────────────────────────────────────────┐    │
│  │           [你的手牌区域]                            │    │
│  └─────────────────────────────────────────────────────┘    │
│                                                               │
│  [按钮栏] [教练提示] [退出]                                  │
│                                                               │
└─────────────────────────────────────────────────────────────┘
                    [右侧: 团队聊天面板]
```

#### 手牌区域 (HandCards)
- 位置: 底部居中
- 卡牌尺寸: 46px × 66px
- 显示数量: 最多27张，自动排列
- 交互: 点击选择，支持多选
- 选中状态: 上移 + 高亮边框

#### 出牌区域 (PlayedCards)
- 上方玩家出牌: 顶部居中，距顶部 65px
- 左侧玩家出牌: 左侧，距左 10px，垂直居中
- 右侧玩家出牌: 右侧，距右 10px，垂直居中
- 卡牌尺寸: 28px × 40px

#### 团队聊天面板 (TeamChatPanel)
- 位置: 右侧固定
- 宽度: 280px
- 高度: 100vh
- 组件:
  - 标题栏（含开关提示）
  - 消息列表（可滚动）
  - 输入框 + 发送按钮

### 3. 教练提示页面 (CoachHintPanel)

#### 布局
- 全屏模态框
- 顶部: 标题 + 关闭按钮
- 中部: 提示内容展示
- 底部: 模式切换

#### 默认模式
- 自动进入高手模式
- 无需点击按钮，自动请求提示

#### 模式切换
- 新手/高手两个选项
- 切换时自动重新请求提示

#### 提示内容展示
- 推荐出牌区域
- 策略解释区域
- 可选牌列表

## 交互设计

### 1. 出牌流程
```
轮到玩家 → 选择手牌 → 点击"出牌" → 验证合法性 → 成功/提示错误
```

### 2. 不出流程
```
轮到玩家 → 点击"不出" → 跳过回合
```

### 3. 教练提示流程
```
点击"教练提示" → 进入提示页面 → 自动请求高手提示 → 显示结果 → 可切换模式
```

### 4. 团队聊天流程
```
输入消息 → 点击发送 → 验证开关状态 → 广播给所有人 → 显示在面板
```

## 响应式设计

### 断点
- 移动端: < 768px
- 平板: 768px - 1024px
- 桌面: > 1024px

### 移动端适配
- 团队聊天面板改为可折叠
- 手牌尺寸自适应
- 出牌区域重新布局

## 动效设计

### 卡牌选择
- 上移动画: 0.2s ease-out
- 高亮边框渐变

### 出牌动画
- 卡牌飞向出牌区: 0.3s ease-out
- 渐入效果

### 消息通知
- 新消息滑入: 0.3s ease-out
- 轻微抖动提示

## 无障碍设计

### 键盘导航
- Tab 键在可交互元素间切换
- Enter 键确认操作
- Esc 键关闭模态框

### 屏幕阅读器
- 所有按钮有 aria-label
- 重要状态有 aria-live 区域
- 语义化 HTML 结构

## 性能优化

### 图片懒加载
- 非关键图片延迟加载

### 组件懒加载
- 教练提示面板按需加载

### 虚拟滚动
- 团队聊天消息列表使用虚拟滚动
