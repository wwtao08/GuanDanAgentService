# 掼蛋教练（Guandan Coach）PRD v2

## 1. 背景
`guandan/` V1 系统已实现掼蛋牌局的基础玩法与教练提示功能：
- 服务器端存在 `BasicAI` 用于 AI 对手出牌。
- 教练提示功能支持本地人机对战（`mode=local`），提供"推荐出牌 + 策略理由"。
- Socket 通信覆盖：`play-cards` / `pass` / `request-coach-hint` / `coach-hint` 等事件。

本 PRD 旨在：
1. 提升 AI 对手的智能水平，使其优先使用 LLM 进行出牌决策。
2. 添加团队聊天系统，让 AI 队友之间可以通过隐晦的提示消息进行交流。
3. 让团队消息融入 AI 的决策过程，提升团队协作能力。
4. 优化 UI 布局，提升用户体验。
5. 优化教练提示的使用流程。

## 2. 目标（Goals）
1. **AI 对手使用 LLM 出牌**：AI 优先使用 LLM 进行出牌决策，失败时回退到 BasicAI。
2. **团队聊天系统**：
   - 支持玩家和 AI 发送团队消息。
   - AI 出牌时自动生成隐晦的提示消息给队友。
   - 团队消息全场可见。
3. **消息融入决策**：AI 在出牌决策时考虑队友的提示消息。
4. **聊天开关控制**：在设置中可开启/关闭团队聊天，默认开启。
5. **UI 优化**：
   - 缩小自己的手牌尺寸。
   - 优化其他玩家出牌的位置，更靠近各自的玩家。
   - 移除普通聊天窗口，只保留团队聊天。
6. **教练提示优化**：
   - 默认进入高手模式。
   - 进入教练提示页面时自动请求提示。
   - 切换模式时自动重新请求提示。
   - 移除次级页面的教练提示按钮。

## 3. 非目标（Non-Goals）
1. 不改变掼蛋规则、牌型判定、出牌合法性校验。
2. 不保证 AI 团队协作必然导致胜利，仅提供协作能力。
3. 不支持私聊，所有团队消息全场可见。

## 4. 关键现状与代码约束
### 4.1 AI 选牌（现状）
- `BasicAI.selectCards(cards, lastPattern)`：当前 AI 回合使用的选牌逻辑。
- `LLMController`：存在但未在 AI 回合中使用。
- 位置：`server/src/ai/basic.ts`、`server/src/ai/llm.ts`

### 4.2 教练系统（现状）
- `CoachHintService`：生成教练提示。
- `ReasonEngine`：生成理由，支持 LLM 和规则兜底。
- 位置：`server/src/coach/`

### 4.3 游戏状态（现状）
- `GameState` 包含玩家位置、手牌、出牌历史等信息。
- 位置：`server/src/game/game.ts`

### 4.4 UI 组件（现状）
- `HandCards`：手牌展示组件。
- `PlayedCards`：已出牌展示组件。
- `TeamChatPanel`：团队聊天面板（新增）。
- `ChatWindow`：普通聊天窗口（已移除）。
- `CoachHintPanel`：教练提示面板。

## 5. 用户与使用场景（User Stories）
### 5.1 AI 对手使用 LLM 出牌
- 作为玩家，我希望 AI 对手使用更智能的 LLM 进行出牌决策，提供更具挑战性的游戏体验。

### 5.2 团队聊天
- 作为玩家，我可以发送团队消息给队友（包括 AI 队友）。
- 作为玩家，我可以看到所有团队消息（全场可见）。
- AI 队友出牌时会自动生成隐晦的提示消息，帮助团队协作。

### 5.3 消息融入决策
- AI 在出牌决策时会考虑队友的提示消息，做出更合适的决策。

### 5.4 聊天开关
- 作为房间创建者，我可以在创建房间时设置是否启用团队聊天。
- 在游戏中可以随时开启/关闭团队聊天。

### 5.5 UI 优化
- 作为玩家，我希望自己的手牌不要占据太多屏幕空间。
- 作为玩家，我希望其他玩家的出牌更靠近他们自己，便于观察。
- 作为玩家，我不希望有两个聊天窗口同时存在。

### 5.6 教练提示优化
- 作为玩家，我希望默认看到高手的教练提示。
- 作为玩家，我希望点击教练提示后立即看到建议，不需要再点击按钮。
- 作为玩家，我希望切换模式时能自动看到对应模式的建议。

## 6. 功能需求（Functional Requirements）
### 6.1 AI 出牌决策
- AI 优先使用 LLM 进行出牌决策。
- LLM 调用失败或不可用时，自动回退到 BasicAI。
- 记录决策来源（LLM 或 BasicAI）。

### 6.2 团队消息发送
- 玩家可以发送团队消息。
- 消息长度限制（最大 50 字）。
- 消息内容必须符合规则（不能直接透露手牌）。

### 6.3 AI 自动生成消息
- AI 出牌时自动生成提示消息（可选）。
- 消息由 LLM 生成，简短隐晦。
- 例如："我能接"、"你先出"、"需要支援"、"小心炸弹"。

### 6.4 消息融入决策
- AI 在出牌决策时接收历史团队消息。
- LLM 提示词中包含团队消息上下文。

### 6.5 聊天开关控制
- 创建房间时可设置 `teamChatEnabled` 参数（默认 true）。
- 游戏中可通过 `toggle-team-chat` 动态切换。
- 关闭时禁止发送和显示团队消息。

### 6.6 UI 优化
- 手牌尺寸缩小约 25%。
- 手牌区域高度相应缩小。
- 其他玩家的出牌位置更靠近各自的玩家信息。
- 移除普通聊天窗口组件。

### 6.7 教练提示优化
- 默认教练模式为"高手"。
- 进入教练提示页面时自动请求提示。
- 切换教练模式时自动重新请求提示。
- 移除教练提示面板中的"教练提示"按钮。
- 退出教练提示页面后，下次进入时重新请求。

## 7. 非功能需求
- 消息历史保留最近 50 条。
- 团队消息广播延迟 < 100ms。
- LLM 调用超时时间：10 秒。
- UI 响应时间 < 100ms。

## 8. 数据约束
- 团队消息不得包含具体牌面信息。
- AI 生成的消息必须经过内容过滤。
